# CPE-011A---CPE21S2-Data-Management-System

# Course Description 

The course introduces the students to the database and design concepts as part of a larger whole by placing them within the systems analysis framework and advanced database development, 

administration, management, security, and database implementation techniques. In this course, students create relational databases, write SQL statements to extract information to satisfy 

business reporting requests, create entity relationship diagrams (ERD) to design databases, and analyze table designs for excessive redundancy. As you develop these skills, you will use either

MySQL or PostgreSQL to execute SQL statements and a database diagramming tool such as Visual Paradigm to create ERDs.

Course Code: CPE 011

Credits: 2 Units Laboratory

Contact Hours: 6 Hours Laboratory

Pre-requisites: CPE 009 - Object Oriented Programming

# Course Objective 

The course aims to provide practical knowledge and skills in database management systems and how they are designed, implemented, and managed in an organization. 

Students must present a database design project implemented and integrated into a software application solving a specific problem. 

# Course Outcomes 

At the end of the course, the students should be able to:

Analyze existing database designs using fundamental database concepts and design rules (SO 7)

Create Entity-Relationship (ER) Diagrams based on specific requirements (SO 7)
Apply SQL Programming in database development (SO 7)

Apply advanced database techniques such as SQL Scripting, Stored Procedures, Stored Functions, Triggers in Database Development (SO 7)

Create a database design and application using any programming language for a specific client. (SO 5 and 7)

# STUDENT OUTCOMES ADDRESSED BY THE COURSE

SO7- acquire and apply new knowledge as needed, using appropriate learning strategies.
